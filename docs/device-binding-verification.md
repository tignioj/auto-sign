# Store 设备绑定真机验证

2026-10-24（北京时间），使用 AutoSign **1.11.0 / build 22** 和 AutoSign Store **1.4.0 / build 9** 在 iPadmini7（iPad mini A17 Pro / iPad16,1，iPadOS 27.0.1）完成验证。Mac 发布构建从已提交的源码生成，不包含本地尚未提交的设备移除功能。

| 验证 | 结果 |
| --- | --- |
| 旧版升级 | 通过运行中的新版 Mac 局域网安装服务，将已安装的 Store 1.3.0 覆盖升级到 1.4.0；保持原应用标识、签名团队及配对记录 |
| 连接后自动选择 | 启动后显示已连接 Mac，设备选择为 iPadmini7，并显示已绑定本机提示；本地首次生成的绑定与实际安装目标一致 |
| 完整重新签名 | 再次由新版 Mac 下载、签名、覆盖安装相同版本，重开仍自动选中 iPadmini7，绑定值保持一致 |
| 旧选择冲突 | 重新签名后的启动参数将旧版按 Mac 保存的选择覆盖为另一台设备，界面仍根据安装绑定选择 iPadmini7 |
| 仅更新描述文件续签 | 手机服务的刷新任务实际向 Apple 请求新描述文件，安装并从设备读回验证；任务确认有效期延长，未重装，前后应用安装位置相同，绑定保持一致 |
| 最终重开 | 清除测试启动参数后重新启动 Store，保留原有配对并连接 Mac |

覆盖安装沿用既有开发证书。描述文件续签遵循本机原有设置，任务内启动验证关闭；另行通过 CoreDevice 启动并截图确认应用界面、连接状态和设备选择。一次描述文件连接中断经现有重连逻辑恢复，最终读回校验成功。

测试用临时源只监听 Mac 回环地址，完成后已移除，并恢复原正式 Store 源关联。现有其他应用未参与本轮安装及续签。原始本地报告、任务记录、设备偏好和截图保存在被 Git 忽略的 `dist/DeviceTests/device-binding-20261024/`，不随发行版发布。

发布源码的 Mac 自动化测试在 English、简体中文下各 **149 项通过**；Store 核心测试 **35 项通过**，源生成测试 **7 项通过**。Mac Release 应用构建和代码签名验证、Store arm64 真机包构建及 v1.4.0 源元数据校验通过。其他真机、系统版本和首次无配对安装未在本轮实测。
